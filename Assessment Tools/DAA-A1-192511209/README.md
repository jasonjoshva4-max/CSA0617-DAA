# DAA Assignment 1 (CO1) — Search Strategies for a Student Record System

**Name:** `<YOUR NAME>`  **Reg No:** `<YOUR REG NO>`  **Group:** A (third algorithm: hash table)
**Report:** `report/DAA_A1_<RegNo>.pdf`

## Algorithms

| # | Algorithm | Style | Strategy | Preprocessing | Search cost |
|---|-----------|-------|----------|---------------|-------------|
| 1 | Linear search (`src/algo1_linear.cpp`) | iterative | brute force | none | Θ(n) average/worst |
| 2 | Binary search (`src/algo2_binary.cpp`) | recursive | decrease-and-conquer | merge sort of a key index, Θ(n log n) | Θ(log n) |
| 3 | Hash table, separate chaining (`src/algo3_hash.cpp`) | iterative lookup | transform-and-conquer (space for time) | build table, Θ(n) | Θ(1) expected |

The dataset generator (`src/dataset_generator.cpp`) uses the **last 4 digits of the reg no as the seed**, always includes the student's own reg no (a "found" test) and never includes reg no + 1 (a "not found" test).

## How to run

### 0. Put your details in `src/config.h`

```cpp
inline constexpr long long   REG_NO = 231801123;      // your reg no
inline constexpr const char* NAME   = "YOUR NAME";
```

The program refuses to run until these are set.

### 1. Install a C++ compiler (one time)

- **Windows:** install [MSYS2](https://www.msys2.org), open the *MSYS2 UCRT64* terminal and run `pacman -S mingw-w64-ucrt-x86_64-gcc make`. (Or use WSL Ubuntu and follow the Linux line.)
- **macOS:** `xcode-select --install`
- **Linux:** `sudo apt install g++ make`

Check with `g++ --version` (any version supporting C++17, i.e. g++ 9 or newer).

### 2. Build (from the repository root)

```
make
```

If `make` is not available, run the same command it runs:

```
g++ -std=c++17 -O2 -Wall -o daa src/benchmark.cpp src/algo1_linear.cpp src/algo2_binary.cpp src/algo3_hash.cpp src/dataset_generator.cpp
```

`-O2` turns on compiler optimisation; always benchmark with it.

### 3. Run (from the repository root, so results land in `results/`)

| Command | What it does | Screenshot to save |
|---------|--------------|--------------------|
| `./daa test` | Task 8: fixed test cases, edge cases, random cross-check at all four sizes | `screenshots/task08_correctness_test.png` |
| `./daa bench 1000` | Task 9: benchmark for n = 1,000 | `screenshots/task09_runtime_1000.png` |
| `./daa bench 10000` | n = 10,000 | `screenshots/task09_runtime_10000.png` |
| `./daa bench 100000` | n = 100,000 | `screenshots/task09_runtime_100000.png` |
| `./daa bench 1000000` | n = 1,000,000 | `screenshots/task09_runtime_1000000.png` |
| `./daa task12` | Task 12: 50,000 searches on 1,000,000 records + daily update | `screenshots/task12_benchmark.png` |
| `./daa gen 1000` | writes a sample dataset to `data/students_1000.csv` | — |

On Windows (cmd / PowerShell) use `daa.exe test` or `.\daa test`.
`./daa task12 --full-linear` runs all 50,000 linear searches instead of a 2,000-search sample (takes a few minutes).

Every run prints the reg no, name and current date/time at the top, as required for screenshots. Capture the **whole** terminal window with the taskbar clock visible.

### 4. Draw the graphs from your own CSV

```
pip install matplotlib
python src/plot_results.py
```

Graphs are written to `results/graphs/` (Fig 9.1–9.4, 10.1, 11.1, 12.1).

## Reproducibility

- The same reg no gives exactly the same dataset, queries and **comparison counts** on any compiler or OS (the generator uses `mt19937_64` with its own mapping and shuffle).
- **Times** depend on the machine. Each timing is an average over repeated runs of at least 200 ms. Close other programs before benchmarking and keep the laptop plugged in.
