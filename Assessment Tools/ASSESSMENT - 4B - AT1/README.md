**Student:** Jason Joshva M J

This project contains standard-library Python demonstrations for the six tasks in DAA Assignment 4B.

## Run
1. Extract the ZIP.
2. Open the project folder in VS Code or a terminal.
3. Run:
   ```bash
   python main.py
   ```
   On Windows, `py main.py` also works.

No external packages are required.

## Included tasks
1. Word Wrap DP: line reconstruction, line slack/penalty, DP states, width changes and boundary case.
2. Fractional vs 0/1 Knapsack: selected items, counterexample, DP instrumentation and comparison.
3. Routing: Dijkstra, Bellman-Ford, negative-cycle detection, Floyd-Warshall and Warshall.
4. Assembly-line scheduling: DP decisions, route, transfer-time and station disruption tests.
5. MST: Kruskal, Prim and Boruvka traces, alternate MSTs and deployment discussion.
6. TSP: Held-Karp DP, route reconstruction, exhaustive small-case validation, state growth and reflection.
